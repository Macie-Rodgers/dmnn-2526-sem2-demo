Dataset choice

I selected Fashion MNIST for this task. This dataset is appropriate for CNN modelling because it consists of grayscale images of clothing items where the class depends on spatial structure such as edges, contours, shapes, and textures. CNNs are designed for this type of data because convolutional filters can learn local visual patterns and reuse them across different image locations.

Fashion MNIST contains 10 classes, and each image has shape 28 × 28 × 1.

Written interpretation

A single training example is a 28 × 28 grayscale image representing one clothing item. Pixel values encode intensity and neighbouring pixels combine to form meaningful visual structures such as edges, curves, and outlines.

Spatial structure matters because the difference between classes depends on how these local patterns are arranged. CNNs learn small visual detectors that capture edges, shapes, and textures and combine them to recognise objects.

A fully connected network would be inefficient here because it treats every pixel independently and ignores spatial relationships between neighbouring pixels.

Conclusion

CNNs are powerful for image tasks because they exploit spatial structure. Convolutional layers learn local feature detectors, pooling reduces spatial dimensions and improves robustness, and dropout can help reduce overfitting.

The test set must not be used to guide architectural decisions because it is intended to provide an unbiased estimate of generalisation performance. If the test set is used during model development, it can lead to overfitting to the test data and overly optimistic results.

In this experiment, test performance broadly aligns with validation trends. The extended model with dropout shows slightly improved generalisation compared to the baseline model, consistent with its smoother validation behaviour. The differences between models are relatively small, so they should not be over-interpreted.

Overall, architectural decisions influence convergence behaviour and generalisation performance, which is why analysing training dynamics is as important as comparing final accuracy.
